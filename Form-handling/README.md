# Fieldnote form handling

A responsive contact form built with plain HTML, CSS, and JavaScript.

## Features

- Accessible labels and live validation messages
- Email, topic, and message validation
- Message character counter
- Local draft persistence with `localStorage`
- Clear form and send-another actions
- Demo success state after valid submission

## Run

Open `index.html` in a browser. No build tools or dependencies are required.

This is a front-end demo. It does not send data to a server.
